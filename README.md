# Carrito de la compra

## Descripción
Proyecto desarrollado para la Actividad 1 del módulo Desarrollo Web en Entorno Cliente (0612).

La aplicación muestra productos obtenidos desde una API de MockAPI y permite seleccionar las unidades de cada producto para calcular el importe total de la compra.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- MockAPI

## Funcionalidades
- Carga de productos desde una API.
- Visualización del nombre y precio de cada producto.
- Selección de unidades.
- Cálculo automático de subtotales y del total de la compra.
- Validación de las cantidades introducidas.

## Estructura del proyecto
- `carrito.html`: estructura de la página.
- `carrito.css`: estilos de la interfaz.
- `js/Carrito.js`: lógica del carrito de compra.
- `js/app.js`: conexión con la API y actualización de la interfaz.

## Ejecución
Abrir el proyecto con Visual Studio Code y ejecutar `carrito.html` mediante Live Server.

## API
Los productos se obtienen desde una API creada con MockAPI.
